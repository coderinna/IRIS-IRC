Jep 😎 Testataan nyt ennen commitia.

Testi 1 — normaali handshake

Käynnistä Iris normaalisti ja muodosta S2S-yhteys.

Pitäisi edelleen näkyä:

[IRISH] → HELLO ...
[IRISH] ← HELLO ...
[IRISH] → AUTH ...
[IRISH] ← AUTH ...
[IRISH] → SERVER ...
[IRISH] ← SERVER ...
[IRISH] → READY ...
[IRISH] ← READY ...
[IRISH] ✓ CONNECTED ...

Eikä 10 sekunnin jälkeen tule timeoutia.

Testi 2 — jätä handshake kesken

Helpoin testi: avaa TCP-yhteys S2S-porttiin, mutta älä lähetä mitään.

Esimerkiksi toisesta terminaalista:

nc 127.0.0.1 7000

(vaihda 7000 sun oikeaksi S2S-portiksi.)

Odota 10 sekuntia.

Pitäisi tulla:

[IRISH] S2S handshake timeout

ja yhteys sulkeutuu.

Testi 3 — varmista ettei timer jää elämään

Normaalin handshake-testin jälkeen yhteys suljetaan.

Koska CONNECTED tekee:

clearTimeout(this.handshakeTimeout);
this.handshakeTimeout = null;

ja close tekee saman varmistuksena, timeoutin ei pitäisi enää laueta myöhemmin.
